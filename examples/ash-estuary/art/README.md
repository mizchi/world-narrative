# シーンと人物の画像制作

ユーザーが2案目の **B：ペン画と淡彩** を選定した。採用画像の実際の筆致、白い石・灰色の水・曇天の光を基準に、全11シーンを生成した。

[シーン画集](gallery.html) で原寸画像を開ける。港1枚、南の水門4枚、北の採石場6枚。採用した南の到着画を含み、新しい10場面と、旧溝の封鎖を明確にする修正版1枚を内蔵image_genで生成した。この段階では人物の顔を固定せず、小さな作業者や手元で表現した。

現在の[人物画集](character-gallery.html) は、イラ・スイ・アサ・ネネ・アドの5人について、三面図・ポーズ画・表情集を分けた15枚。全員同じ画角の全身像は設定参照に向くが、人物の演技や場面の用途には合わないというユーザーの指摘に合わせた。内蔵image_genで各画像を生成し、Bを画風、最初の全身像を顔・体格・服装の参照として毎回添えた。

| 種類 | 用途・構図 | 保存ファイル |
| --- | --- | --- |
| 三面図 | 同じ縮尺の正面・左側面・背面。体格と衣服を確認する。手持ち品を外す。 | characters/*-turnaround-v2.png |
| ポーズ画 | 人物らしい仕草と表情。動作に応じて画角・寄り・縦横比を変える。 | characters/*-pose-v2.png |
| 表情集 | 同じ寄りの顔4表情を2×2で比較する。感情の演技を参照する。 | characters/*-expressions-v2.png |

ポーズ画は、イラが机越しに相手の話を聞く姿、スイがしゃがんで点検する姿、アサが網を繕う手元の寄り、ネネが作業を中断してためらう胸元の寄り、アドが石に腰掛けて仕事を語る姿。表情集は普段・対話・心配・小さな笑みなどを、各人物の性格と仕事に合わせて指定する。三面図は1536×1024、表情集は1254×1254、ポーズ画は構図に応じた縦横比で保存する。

制作方針と画像の用途・人物への対応は [character-production-plan-v2.json](character-production-plan-v2.json)。表情ごとのラベル、順序、規格化した領域と627×627のピクセル領域も記録する。表情集は一枚の比較画像であり、4枚の独立した表情PNGではない。三面図は制作参照で、厳密な投影や衣服の寸法を保証する3D設計図ではない。

人物の描画方針と初稿の外見案は [character-art-direction.json](character-art-direction.json)。職業など本文の設定と、本文にはない年齢・顔・髪型・服装を分けて記録する。世界JSONの正史には自動追加せず、既存シーンの匿名人物に遡って名前を割り当てない。ネネは本文にある女性として描く。他の人物の外見は今回のデザイン案。

今後の人物入りシーンでは、Bを画風、三面図を衣服・体格、表情集を顔の参照として併用する。必要な場所の画像も、その役割を明記して添える。ポーズ画は演技の一例として使い、背景・画角・仕草・表情は新しい場面に合わせて指定する。[art-direction.json](art-direction.json) の共通シーンプロンプトと人物参照を、この方針へ更新した。

今回の完全なプロンプトは [三面図](character-prompts-turnaround-v2.json)、[ポーズ画](character-prompts-pose-v2.json)、[表情集](character-prompts-expressions-v2.json)。生成履歴・参照画像・寸法・SHA-256は [character-production-generation-v2.json](character-production-generation-v2.json)。元画像とプロジェクト内の最初の5枚は保持する。

最初の全身像5枚は1024×1536のPNGで、[初稿の画集](character-gallery-v1.html) から開ける。当時の[生成プロンプト](character-prompts-v1.json)と[生成履歴](character-generation-manifest.json)を保持し、外見案の参照元として使う。現在の人物画集のプレビューは http://127.0.0.1:4175/character-gallery.html 。

15画像の寸法・ハッシュ、元画像と初稿の保持、人物の参照元、プロンプトと用途の対応、20表情の領域データを確認した。Playwrightで幅1280px／390pxの全15画像、三つの区分への移動、全リンク、横はみ出し・ページエラーなしを確認した。

一覧はHTMLファイルとして開ける。今回の確認用プレビューは http://127.0.0.1:4175/gallery.html 。Playwrightで全11画像の読込み、デスクトップとモバイルの横幅、ページエラーがないことを確認した。

固定した描画方針と共通プロンプトは [art-direction.json](art-direction.json)。南の到着画像はBをそのまま使用し、他のシーンはBを毎回参照する。北の採石場の到着画像は、その後の北の場面で建物と道具の連続性を保つためにも参照する。

[比較ページ](comparison.html)、[Aの原寸](style-a-painterly-v1.png)、[Bの原寸](style-b-ink-wash-v1.png)、[Cの原寸](style-c-gouache-v1.png)。使用ツールと保存先は [generation-manifest.json](generation-manifest.json) に記録する。

| 案 | 画風 | 比較する点 |
| --- | --- | --- |
| A | 油彩風の環境画 | 空間・石・生活道具の質感、静かな不穏さ |
| B | ペン画と淡彩 | 記録を読むような観察の感触、紙と線の密度 |
| C | 平面的なガッシュ | 形と配色の統一、読みやすい景観 |

同じ場面、構図の意図、曇天、白い石と灰色の水を共通にする。生成時の構図が完全に同じになることは保証しない。画像内には文字やUIを入れない。最初の到着場面では道を壊さず、秘密や不可逆な選択の結果を先に描かない。

目視確認では、Aは質感と奥行き、Bは細い輪郭と淡彩、Cは色面のまとめ方に違いがある。三案とも写実的な細部が多く、Cも完全な平面表現にはなっていない。次の調整で省略や不穏さを強める余地がある。小さな人物と建物配置は画風試作の解釈であり、登場人物の固定デザインや地理の正史としては採用していない。

ユーザー指定モデルはgpt-image-2.5。使用可能な内蔵image_genにはモデル指定欄がないため、このモデルへの固定は確認できない。生成プロンプトは [style-candidates.json](style-candidates.json) に保存する。

描画方針には、配色・筆致・光・形の省略・人物の表現・避ける要素を記録した。生成プロンプトは共通方針と各シーンの差分を分け、scene-prompts-wave-*.jsonに保存する。修正時は一度に一つの軸を変える。

後続シーンの候補と表示条件は [scene-plan.json](scene-plan.json) に保存する。本文と同様に秘密の開示条件を守り、到着画に結果や真相を混ぜない。人物画も選択前の状態として描き、記憶の提供や家族の運命、秘密の真相を図解しない。

調査画と到着画は、画像中の未修理状態と一致する条件に限定した。修理後は専用の場面を使い、北の窯修理と溝修理を一枚の成功結果に統合しない。表示条件は制作データとして保存しており、ゲームプレイヤーへの画像組込みはまだ行っていない。

帳面の筆跡・数値・建築の細部は画像としての解釈であり、世界の正史へ取り込まない。資料の確定情報はゲーム本文で提示する。修理後の南の画はv2を使用し、v1も制作履歴として残す。修正版には人物配置の変化もあるため、すべての局所編集が画素単位で保たれるわけではない。

生成履歴、参照画像、ファイルの寸法・SHA-256は [scene-generation-manifest.json](scene-generation-manifest.json)。各場面の完全なプロンプトはscene-prompts-wave-1/2/3.json、局所修正はscene-prompts-correction-1.jsonに保存した。
